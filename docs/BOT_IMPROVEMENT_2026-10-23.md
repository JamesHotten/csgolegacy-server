## 1. Mirage / Dust2 入口分工

只作用于标准开局防守，先生成原通用角度，再尝试用可见命名入口替换缓存观察目标。
每点独立记录已分配入口：优先未覆盖且可见的入口，无法覆盖新入口时才允许交叉架同一入口；
所有候选均不可见时保留通用回退，不假装已有覆盖。不会为了观察入口修改移动路线。

- Mirage A：TRamp、PalaceInterior、Connector；B：Apartments、Catwalk。
- Dust2 A：LongA、Short；B：UpperTunnel、BDoors。
- 目标只在回合分配／重新规划时计算；使用视线检测、NAV 中心及近侧边界，不在每帧搜索。
- 前压、堵点、掉包守包、见包匪回防及下包后回防仍走原有流程。
- 接敌、开火、受伤、必要交互和已执行道具的让权规则保留。
- 开关：`sm_bot_ct_entrance_watch 0`，随后 `sm_ct_tactics_replan` 或等待下一回合。
  关闭会清除命名锚点解析缓存，重新规划时回到之前的通用行为。

### NAV 地点索引

现有 NAV 插件将文件中的 1..N 地点编号直接用作 0..N-1 字符串数组下标。
[Valve 的 NAV 目录代码](https://github.com/ValveSoftware/source-sdk-2013/blob/master/src/game/server/nav_file.cpp)
明确将 0 留作未命名，其余项减 1 解码。
本次新增独立只读 `NavMeshArea_GetPlaceCanonical`，不改变旧 `NavMeshArea_GetPlace`，
也不写 NAV 数据或改变其寻路算法。Mirage／Dust2 在入口开关启用时使用正确接口解析开局锚点；
其他七图、T 和旧 API 消费者不迁移。接口缺失时回退，不让 CT 插件加载失败。

用当前 SourcePawn 编译旧 NAV 源码时，需要显式的 Function 类型和返回 cell 转换；
只做同一 cell／动态回调的编译兼容处理，未重写寻路。旧 NAV 源码仍有编译警告，不能宣称全库零警告。

### 测试边界

静态检查不等于正确覆盖入口。空服探针另验证 T 出生地标签、缓存观察稳定、原生声音干扰和开火释放。
测试先等原生视角稳定，再开始干扰采样，并单独设置 10 秒初始收敛上限；85% 对准门槛不变。
测试杀死并移除对方测试 C4，避免“藏到地图下”仍被原生敌人记忆识别、触发合法回防而污染结果。
测试后必须卸载测试插件并重启，不能继续拿隔离场景游玩。

### 本次验收结果

- 空服真实原生接口复验：Mirage 旧出生地标签 `BombsiteA`、新接口 `TSpawn`；Dust2 旧标签
  `OutsideTunnel`、新接口 `TSpawn`。旧接口保留，没有为了让测试通过而全局改标签。
- Mirage 空间入口搜索后观察到 A 坡、B 公寓命名目标，部分站位仍使用通用回退，
  **未实现所有站位对宫殿／连接／小道入口的完整覆盖**。
- Mirage 去除诊断日志后的最终探针 61/69 对准，通过原 85% 门槛；Dust2 69/69。
  缓存方向保持、开火释放和随后允许原生转向均通过。
- Dust2 正式输出 A 点 LongA/Short、B 点 UpperTunnel/BDoors；同点可见未覆盖入口优先。
- 原始 2 秒预热的首轮曾失败；之后单独测初始收敛，再测试声音竞争，没有降低通过门槛。
  测试中的地图下隐藏敌人还曾合法触发“看到包匪全回防”，已将这一不充分的隔离方式改为移除敌人和 C4。
- 缺失阵容运行检查：五个预期名字全部出现，先设旧队标／旧队名再切到无图队伍，确认旧身份已清除。
- 32 项 PowerShell 回归检查通过；掉包守包实服探针 `CT_GUARD_PROBE_PASS failures=0`，
  包括原生掉包假值不被提升、全员守包、连续交火让权和安静归位。
- 测试插件移到 disabled，目标游戏服进程已关闭；没有提交或推送 Git。

这些是隔离场景和静态回归，不是长期崩溃／性能压测，也不是所有地图的实战效果证明。

## 2. 阵容资源缺失

可复现检查：`tests/test_bot_roster_assets.ps1 -ServerDir <服务器目录>`。
原始发布 ZIP 同样缺少 zmb、happ、Leomonster 档案及 larg.svg/larg.cfg；不是此次朝向改动删除了资源。

`mods/patch_bot_roster_assets.ps1` 只为缺失名字追加现有 `ProP+Rifle+RiflePersonality` 模板档案，
与队内已有通用步枪手模板一致。这是兼容回退，不是对真人职业水平的模拟；已有档案和阵容名字不改。
测试验证原档案完整保留，重复运行不追加重复档案，也不修改其他队伍。

本地没有 larg 原队标，因此把该队配置改为显式无图；保留队名和五人名单，清除上支队伍旧图标，
避免伪造或冒用队标。以后补齐原图及同 ID 的队名 cfg，再把该队 logo 设回 larg 即可。
部署入口已调用修复脚本，新机器同样生效。

# CT/T 通用优化与十图战术

通用层适用于有完整 A/B 包点和 NAV 的爆破地图。CT 标准开局不再发布明显撞墙的固定观察命令：远端碰墙但前方有可用空间时缩短枪线；没有可用方向则保留移动订单、交由原生 AI 观察。T 提前开攻要求持包 BOT 也接近集合位；按三维距离判断到位。真人持包、接敌、硬超时及紧急下包不受此门槛拖延。

地图层优先使用实测 NAV 地名。CT 从原站位选可见入口，尽量分担不同入口；看不到入口时，最多试四个同包点、同层的邻近站位，仍不行就回退。Inferno 保留原专项站位和精确到位规则。T 让包匪进入已验证的主攻集合位；分推在入口有效时最多派两名 BOT 去第二入口，狭窄处用同侧邻近站位补齐；开攻后向同一包点汇合。路径必须通过 NAV 连通性及站立空间检查。入口无效时可用备用入口，两个都不可用则回到通用规划。这里配置的是**集合目标**，不是强制每一步经过的路径。

分开回退（下一回合或管理员重新规划后生效）：

```text
sm_bot_ct_clear_opening_watch 0
sm_bot_t_sync_carrier_ready 0
sm_bot_ct_entrance_watch 0
sm_bot_t_map_routes 0
```

前两个关闭各自的通用改动，后两个关闭各自的命名入口改动。Inferno 专项仍由 `sm_bot_ct_inferno_watch` 独立控制。原投掷录像、交火释放、经济、守包及回防规则未替换；本次不重新录制道具，不修改 `mg_active`。

验证入口：`tests/test_tactical_map_profiles.ps1` 核对地名与回退接线；`tests/tactical_maps_runtime_probe.sp` 是仅限空服的 128-tick 切图测试，检查 CT 固定枪线、T 在 A/B 的包匪和队友集合订单、模拟接敌后的进攻切换。它不评估整场真人实战、对枪强度或 BOT 走完整条路线的成功率。

# BetterBots 反应速度

这份可回滚的 BetterBots 构建把职业 BOT 的首次接敌速度调到更接近人的范围，不改变移动战术、购买、投掷物或真人输入。

| 类型 | 反应时间 | 转头最大加速度 |
| --- | --- | --- |
| 顶级 BOT（sh1ro、ZywOo、ropz、donk、m0NESY） | 随机 0.18–0.22 秒 | 随机 6000–7500 |
| 其他职业 BOT | 随机 0.22–0.30 秒 | 随机 4500–6500 |
| 普通 BOT | 保持原生配置 | 保持原生配置 |

旧构建的顶级 BOT 是 **0.0 秒**和 **100000**；第一版人类化配置为顶级固定 **0.20 秒/7000**、其他职业 **0.23–0.38 秒/3500–6000**。当前配置让每名职业 BOT 在连接时抽取一个稳定的个人数值，避免所有顶级选手拥有完全相同的机械反应，同时移除不符合职业玩家水平的 0.38 秒慢端。

这些区间用于模拟“发现可见敌人并开始作出枪械反应”，不是完整击杀时间。实际第一枪还需要完成转头、瞄准、停步、开镜及武器自身限制，因此通常晚于表中下限。研究也表明职业 FPS 的反应速度取决于目标大小和精度要求，不能用一个固定的网页点击成绩代表所有交战。

仅调整引擎 BotProfile 不足以限制 BetterBots 的自定义步枪开火逻辑。因此首次看见一个新目标时，枪械开火按该 BOT 的反应时间延后；目标短暂消失不足 0.75 秒再出现不会重新等待。只限制枪械 `IN_ATTACK`，不阻断烟、闪、火的录制投掷或真人操作。

`addons/sourcemod/configs/bot_stuff.cfg` 会同步显示普通职业区间以及顶级区间的中位参考值，但当前 SourcePawn 核心**并不从这个文件读取反应参数**；以 `bot_stuff.sp` 编译出的 `bot_stuff.smx` 为准。要再调整，修改 `mods/install_ct_tactics.ps1` 中的默认值后重新编译，并在服务器停止时安装。

安装器保留接入前的 `bot_stuff.original.sp/.smx`。如需完整恢复旧 BetterBots，先停服再运行仓库的 `rollback_ct_tactics.ps1`；这也会一并移除 CT/T 战术桥接。调整前后可用 `tests/test_bot_reaction.ps1` 做静态回归，并在游戏中观察第一次见人到开枪的体感。
